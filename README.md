## Fictologist
A worldbuilding tool for creatives to store and sort pieces of lore and mythos for their fictional worlds. A historian chatbot can use this for quick conversations and potentially to help fill in the gaps if asked.  

## Requirements

[Ollama](https://ollama.com/download) for Chat bot embeddings with local Mistral AI model.
